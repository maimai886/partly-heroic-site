遊戲遇到問題、或有任何疑問，先看看下面的常見問題；找不到答案的話，請到最下面的「聯絡我們」回報。

常見問題

子母畫面（懸浮）怎麼開？
  1. 在戰鬥畫面按「懸浮」按鈕，戰鬥畫面就會變成子母畫面的小視窗。
  2. 回到主畫面或打開其他 App，小隊會在小視窗裡繼續冒險。小視窗可以拖曳移動、用兩指縮放，推到螢幕邊緣可以暫時收起。
  3. 小視窗的按鈕可以直接操作：營火休息、使用藥水、施放大招。
  4. 想回到完整畫面，點小視窗回到 App，或在 App 裡按「收回」。關掉子母畫面後，冒險會暫停。
  • 自動懸浮：「強化」面板（左上的「強化」按鈕）裡的「離開 App 時自動懸浮」預設是關閉的。打開後，離開 App 時會自動變成小視窗。
  • 聲音：懸浮時預設不播音樂和音效，不會蓋過你在別的 App 聽的東西。想聽的話，在「強化」面板打開「懸浮時播放音樂」「懸浮時播放音效」。
  • 如果按「懸浮」時出現「目前無法懸浮」，代表這台裝置現在不能開子母畫面。遊戲在 App 裡仍然可以正常玩；方便的話請回報你的機型和 iOS 版本。
存檔在哪裡？換手機會不見嗎？
  • 存檔只存在你的裝置上。本遊戲沒有帳號，也沒有雲端存檔，不需要網路。
  • 刪除 App 會一起刪除存檔，我們沒有副本，無法替你還原。
  • 換新 iPhone 時，如果用 iCloud 備份或電腦備份把整台舊手機還原到新手機，存檔通常會跟著 Apple 的備份一起轉移。只重新下載 App 的話，會從頭開始。
  • 我們無法替你轉移或修改存檔。

怎麼回報錯誤（bug）？
  1. 按下方的「回報問題或提問」，會打開本網站在 GitHub 上的問題回報頁（需要免費的 GitHub 帳號）。
  2. 寫下：App 版本（「強化」面板最下面的「關於」）、手機機型、iOS 版本、發生了什麼、怎麼做會再發生一次。有截圖或螢幕錄影更好。
  3. 回報會公開顯示在網路上。請不要寫姓名、電子郵件、電話、地址等個人資料，截圖也請先確認沒有個人資料。

よくある質問

ピクチャ・イン・ピクチャ（小窓）はどうやって使いますか？
  1. バトル画面で「小窓」ボタンを押すと、バトル画面がピクチャ・イン・ピクチャの小さなウインドウになります。
  2. ホーム画面に戻ったり、ほかのアプリを開いたりしても、パーティはウインドウの中で冒険を続けます。ウインドウはドラッグで移動、2本指で拡大・縮小でき、画面の端に寄せると一時的に隠せます。
  3. ウインドウのボタンで、たき火で休憩、ポーション、必殺技を操作できます。
  4. 元の画面に戻るには、ウインドウをタップしてアプリに戻るか、アプリ内でもう一度ボタンを押します。ピクチャ・イン・ピクチャを閉じると、冒険は一時停止します。
  • 自動で小窓にする設定：アプリを離れたときに自動で小窓にする設定は、初期設定ではオフです。画面左上のボタンから開く強化パネルでオンにできます。
  • サウンド：小窓のあいだは、初期設定では音楽も効果音も鳴りません。ほかのアプリで聴いているものの邪魔をしないためです。同じパネルでオンにできます。
  • 小窓にできないというメッセージが表示された場合、その端末では現在ピクチャ・イン・ピクチャを開けません。アプリの中では通常どおり遊べます。可能であれば、機種名と iOS のバージョンをお知らせください。
セーブデータはどこにありますか？機種変更で消えますか？
  • セーブデータはお使いの端末にのみ保存されます。アカウントやクラウドセーブはなく、インターネット接続も不要です。
  • アプリを削除すると、セーブデータも削除されます。当方は複製を保有していないため、復元できません。
  • 新しい iPhone に、古い iPhone の iCloud バックアップまたはコンピュータのバックアップを丸ごと復元した場合、通常はセーブデータも Apple のバックアップと一緒に移行されます。アプリを再ダウンロードしただけの場合は、最初からになります。
  • 当方がセーブデータを移行したり、変更したりすることはできません。
対応機種を教えてください。
  • iOS {{ site.min_ios }} 以降の iPhone{% if site.ipad_supported %}・iPad{% endif %}に対応しています。
  • 現在、Android 版はありません。
不具合はどうやって報告すればいいですか？
  1. 下の「不具合の報告・お問い合わせ」を押すと、本ウェブサイトの GitHub 上の報告ページが開きます（無料の GitHub アカウントが必要です）。
  2. アプリのバージョン（強化パネルのいちばん下に表示）、機種名、iOS のバージョン、何が起きたか、どうすれば再び起きるかを書いてください。スクリーンショットや画面収録があると助かります。
  3. 報告はインターネット上で公開されます。氏名、メールアドレス、電話番号、住所などの個人情報は書かないでください。スクリーンショットにも個人情報が写っていないか確認してください。
料金はかかりますか？広告はありますか？

本ゲームは現在無料で、アプリ内課金や広告はありません。
